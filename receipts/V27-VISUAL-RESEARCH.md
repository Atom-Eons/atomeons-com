# AtomEons V27 visual research ruling

Date: 2026-08-26

## Actual problem

V26 had strong editorial hierarchy and a clear product front door, but its Three.js layer read as ambient decoration. The user asked for a much larger jump in visual invention without losing the human-readable product story.

## References studied

- Fable 5 working showcase: ten executable browser experiments, including a 220,000-particle universe and cursor-driven fluid.
- Genesis: one coherent particle world with direct manipulation, restrained interface chrome, and a transformation vocabulary.
- mesh3d gallery: current Three.js work led by product storytelling, cinematic sequencing, and real-time interaction.
- Official Three.js examples and responsive guidance.

## Reusable interaction grammar

1. The visual is an instrument, not wallpaper.
2. One coherent world beats many unrelated effects.
3. Physical response must be immediate: pointer wake, touch pulse, scroll turn.
4. The product remains the focal object and the calls to action remain ordinary HTML.
5. Motion must have a calm fallback and must not hijack scrolling.
6. Mobile gets the same story with a lower-density composition, not a broken desktop scene.

## AtomEons-specific synthesis

V27 is a living artifact field: 44,000 GPU-driven particles braided around a black-chrome machine core, with safety-orange and cobalt signal objects. It frames the real CableBox television as evidence of the company claim. The field bends toward the visitor and releases a shockwave on contact, but it never blocks the product actions.

## Falsifiers

- If the first screen does not say what CableBox is within five seconds, the spectacle failed.
- If the canvas blocks a link, touch scroll, or reduced-motion preference, the interaction failed.
- If mobile loses the real product image or primary action, the responsive design failed.
- If graphics make text contrast unreliable, the art direction failed.
- If the production build or live runtime logs WebGL errors, the implementation failed.
